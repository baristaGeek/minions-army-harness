## Git

- `git`: branch, commit, inspect history, and push changes.

## GitHub

- `gh`: create pull requests and inspect GitHub repository metadata.

## Workflow

- `codex`: execute the task workflow.
- `specify-cli`: bootstrap Spec Kit when needed.

## Language Tooling

- `node`: run JavaScript and Node-based tooling.
- `npm`: install dependencies and run package scripts.
- `python`: run Python tooling and small scripts.
- `uv`: manage Python tooling and dependencies.
