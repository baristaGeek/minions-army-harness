# Constitutions

`execution/constitutions/` contains the engineering standards and execution profiles used by the project.

## Structure

```text
execution/constitutions/
  README.md
  core/
    basic.md
    standard.md
    professional.md
    enterprise.md
  profiles/
    README.md
    tools/
      agent-tools.md
    angular.yaml
    dotnet.yaml
    golang.yaml
    javascript.yaml
    nodejs.yaml
    python.yaml
    react.yaml
```

## Core

`core/` contains the maturity levels that define engineering expectations.

## Profiles

`profiles/` contains tool and stack profiles used by the execution workflow.

Use `core/` for standards and `profiles/` for tool and stack metadata.
