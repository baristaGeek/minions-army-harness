# Migration Versions

Alembic migration revision files live in this directory.

## Create A Revision

```bash
alembic revision --autogenerate -m "describe change"
```

## Apply Revisions

```bash
alembic upgrade head
```

## Revert One Revision

```bash
alembic downgrade -1
```

## Review Rules

- Review autogenerated operations before committing.
- Keep each revision focused on one schema change.
- Use descriptive revision messages.
- Do not edit revisions that have already been applied in shared environments.
